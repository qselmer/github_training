# Class 01 — Git and GitHub fundamentals

## Learning objectives

By the end of this class, students should be able to:

1. distinguish Git from GitHub;
2. explain the difference between GitHub and cloud storage services;
3. configure Git locally;
4. create a repository;
5. understand `status`, `add`, `commit`, `push`, and `pull`;
6. complete the first repository practice.

## Suggested class sequence

1. Why version control is necessary.
2. Git versus GitHub.
3. GitHub versus Google Drive.
4. The local Git workflow.
5. Connecting a local repository to GitHub.
6. Guided practice.
7. Introduction to branches and pull requests.

Each student should finish the class with a public practice repository containing a `README.md` and at least two commits.
