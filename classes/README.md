# Classes

Esta carpeta organiza el contenido por sesión de aprendizaje.

## Convención de nombres

Cada clase debe comenzar con un número de dos dígitos:

```text
01-introduction/
02-local-workflow/
03-remote-workflow/
04-branches-pull-requests/
```

## Estructura sugerida por clase

```text
01-introduction/
├── README.md       # Objetivos y resumen
├── slides/         # Diapositivas
├── examples/       # Ejemplos usados en clase
└── exercises/      # Prácticas y soluciones
```

Git no registra carpetas vacías. Por ello, cada nueva carpeta debe contener al menos un archivo, normalmente un `README.md`.
