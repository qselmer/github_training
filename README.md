# Git and GitHub Training

Repositorio central para organizar materiales, diapositivas y prácticas de las clases de Git y GitHub.

## Estructura

```text
github_training/
├── classes/                  # Material organizado por clase
│   └── README.md
├── git-github/               # Guías y prácticas específicas de Git y GitHub
│   ├── README.md
│   ├── practices/
│   │   └── 01-first-repository.md
│   └── cheatsheets/
│       └── basic-commands.md
└── README.md
```

## Ruta de aprendizaje

1. Comprender la diferencia entre Git y GitHub.
2. Configurar Git en la computadora.
3. Crear un repositorio local.
4. Registrar cambios con `add` y `commit`.
5. Conectar el repositorio local con GitHub.
6. Trabajar con ramas y fusiones.
7. Colaborar mediante pull requests.

## Uso

Cada nueva sesión debe añadirse dentro de `classes/` usando nombres ordenados, por ejemplo:

```text
classes/
├── 01-introduction/
├── 02-local-workflow/
├── 03-remote-workflow/
└── 04-branches-pull-requests/
```

La carpeta `git-github/` contiene las prácticas reutilizables, guías rápidas y materiales técnicos del curso.
