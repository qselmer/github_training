# Git and GitHub

Material práctico para aprender control de versiones desde un nivel inicial hasta un flujo colaborativo.

## Contenido

- `practices/`: ejercicios guiados.
- `cheatsheets/`: comandos de consulta rápida.

## Flujo básico

```text
working directory → staging area → local repository → GitHub
```

Comandos principales:

```bash
git status
git add .
git commit -m "Describe the change"
git push
```

## Objetivo

Al finalizar las prácticas, el estudiante podrá crear repositorios, registrar cambios, sincronizar trabajo con GitHub, usar ramas y participar en pull requests.
